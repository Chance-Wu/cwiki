## cwiki 记忆

> 是否写入看会话注入的「cwiki 写入决策」；怎么写看 `cwiki-save` skill。本段只保留必须常驻的硬约束，细则以 skill 为准。

- 开工先 `memory_search` 检索；出现用户纠正、技术决策、踩坑、隐性约定等信号时按 `cwiki-save` 用 `memory_save` 提交，需纠偏时用 `memory_update`。
- 收尾做一次语义回看：把本会话的决策、原理、偏好、踩坑逐条过一遍并按需 `memory_save`；`memory_checkpoint` 只分析已采集事件，不能替代回看。课程/方案/讲解类会话不能跳过；计划类条目按周 `memory_update`，不重复新建。
- 不写入：凭据、密钥、令牌、未脱敏日志、一次性状态查询，以及可从代码或 git 直接推导的内容。
- 工具不可用时继续任务并注明“记忆不可用”，不要编造记忆内容。

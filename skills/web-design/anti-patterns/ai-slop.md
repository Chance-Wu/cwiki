# AI Slop Detection

Warn against:
- generic hero copy
- gradient dependency
- excessive glassmorphism
- card explosion
- pill explosion
- decorative glow
- oversized typography
- badge spam
- icon decoration
- excessive shadows
- nested containers
- meaningless animation
- generic SaaS layouts

For every decorative element ask:
Does this improve comprehension, hierarchy, identity, or interaction?

If not, remove it.

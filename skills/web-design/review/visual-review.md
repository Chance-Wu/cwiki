# Visual Review

The rendered UI is the source of truth.

## Sequence

1. First impression
2. Structure
3. Hierarchy
4. Density
5. Typography
6. Color
7. Components
8. Interaction
9. Responsive behavior
10. AI-slop detection

## Questions

### First Impression
- What attracts attention?
- Is that the intended focal point?
- Does the page feel calm or noisy?
- Does it feel product-specific?

### Structure
- Are major regions aligned?
- Is the content frame appropriate?
- Is whitespace intentional?

### Hierarchy
- Is the primary action obvious?
- Can the page be understood quickly?
- Are secondary elements quiet?

### Density
- Is information too sparse?
- Is it too dense?
- Are controls wasting space?

### Typography
- Is hierarchy clear?
- Is text too large?
- Is metadata too prominent?

### Color
- Is accent overused?
- Are semantic colors consistent?
- Is contrast sufficient?

### AI-Slop
Check gradients, glass, card explosion, pill explosion, badge spam,
decorative icons, oversized typography, excessive shadows, generic SaaS patterns.

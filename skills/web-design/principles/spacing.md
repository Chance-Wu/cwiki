# Spacing Principles

Preferred conceptual scale:

4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64 / 80

## Relationship Rule
Related elements are closer.
Unrelated groups have more separation.

## Typical
label → value: 8
field → field: 16
group → group: 24
section → section: 40–64

Avoid arbitrary spacing values unless the design system requires them.

# Typography Principles

Typography establishes hierarchy before color and decoration.

## Rules
- Use a restrained type scale.
- Limit font weights.
- Keep body text readable.
- Use line-height appropriate to content.
- Avoid oversized headings in utility interfaces.
- Keep metadata visually quiet.

## Hierarchy
Display → Page title → Section title → Body → Secondary → Metadata → Caption

## Review
Ask whether the user can identify title, section, content, and metadata without reading everything.

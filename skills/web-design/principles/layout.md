# Layout Principles

## Goal
Create a clear spatial structure before styling details.

## Rules
- Establish the primary content region first.
- Use a consistent container width.
- Align major regions to a shared grid.
- Prefer fewer layout primitives.
- Use whitespace to separate semantic groups.
- Avoid nested containers without semantic purpose.

## Common Structures
- Sidebar + content
- Master + detail
- Toolbar + table
- Split view
- Single-column reading layout
- Dashboard grid

## Questions
- What is the primary workspace?
- What is navigation?
- What is secondary context?
- What should remain visible while the user works?

# Responsive Design

Responsive design means changing behavior, not only dimensions.

## Desktop
Multi-column, persistent navigation, dense controls.

## Tablet
Reduce columns and navigation complexity.

## Mobile
Prioritize core content, simplify toolbars, use drawers or bottom navigation where appropriate.

Ask:
- What must remain visible?
- What can collapse?
- What can become secondary?
- What interaction changes on touch?

# Color Principles

Start with neutral structure and add semantic accents.

## Base
- background
- surface
- surface-muted
- border
- text
- text-secondary
- text-muted

## Semantic
- primary
- success
- warning
- danger
- info

## Rules
- Accent colors communicate meaning.
- Do not use many competing accents.
- Do not use gradients as a substitute for identity.
- Do not rely on color alone for status.
